# 日志免提醒设置

需求：在系统设置中自行选择不提醒的日期。支持每周固定星期以及指定日期，两者任一命中即跳过当天员工日志的提交/逾期提醒，按北京时间判断。保留原日志截止时间、审批提醒及工作计划提醒；已有提醒不删除。
